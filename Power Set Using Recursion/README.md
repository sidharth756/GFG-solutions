## 📝 Problem Description

You are given a string. You need to return the power-set (in any order) of the string. Note: The string s contains lowercase letter of alphabet.

### 🔢 Examples

**Input:**
```
 s = a 
```
**Output:**
```
 ["","a"] 
```
**Explanation:**
 empty string and "a" are only sets. 
**Input:**
```
 s = abc 
```
**Output:**
```
 ["", "a", "ab", "abc", "ac", "b", "bc", "c"] 
```
**Explanation:**
 empty string, a, ab, abc, ac, b, bc, c are the sets.

### 📌 Constraints

```
1 ≤ s.length() ≤ 10
```
